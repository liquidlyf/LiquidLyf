## কীভাবে ইনস্টল করবেন

LiquidLyf Play Store থেকে নয়, আমাদের ওয়েবসাইট থেকে নামাতে হয়, তাই অ্যান্ড্রয়েড কয়েকটা বাড়তি প্রশ্ন
করে। সব মিলিয়ে মিনিট দুয়েক লাগে।

   করতে পারে, তাহলে **"তবুও ডাউনলোড করুন"** (<span lang="en">Download anyway</span>) চাপুন।

   `LiquidLyf.apk` চাপুন।

3. **ইনস্টলের অনুমতি দিন।** প্রথমবার অ্যান্ড্রয়েড জানাবে, আপনার ব্রাউজার দিয়ে অ্যাপ ইনস্টল করার অনুমতি
   নেই। **"সেটিংস"** (<span lang="en">Settings</span>) চাপুন, **"এই উৎস থেকে অনুমতি দিন"**
   (<span lang="en">Allow from this source</span>) চালু করুন, তারপর ফিরে আসুন।

   [SCREENSHOT 2]

   অ্যান্ড্রয়েড ৭-এ এর বদলে **"অজানা উৎস"** (<span lang="en">Unknown sources</span>) চালু করুন। কিছু
   ফোনে (যেমন realme, Xiaomi বা Samsung) সুইচটা থাকে সেটিংস → অ্যাপ → বিশেষ অ্যাপ অ্যাক্সেস → অজানা অ্যাপ
   ইনস্টল করুন-এ।

4. **ইনস্টল করুন।** **"ইনস্টল করুন"** (<span lang="en">Install</span>) চাপুন।

5. **Play Protect সাবধান করলে** **"আরও বিস্তারিত"** (<span lang="en">More details</span>) চাপুন, তারপর
   **"তবুও ইনস্টল করুন"** (<span lang="en">Install anyway</span>)।

   নিতে পারেন।

6. **LiquidLyf খুলুন,** ভাষা বেছে নিন, তারপর **"Google দিয়ে চালিয়ে যান"** চাপুন, অথবা আপনার ইমেইল
   দিয়ে সাইন ইন করুন।

## এটা কি আসল LiquidLyf?

LiquidLyf শুধু এই পাতা থেকে বা [আমাদের GitHub রিলিজ](https://github.com/liquidlyf/LiquidLyf/releases)
থেকে নামান। অন্য কোথাও পাওয়া কপি ভুয়া হতে পারে। সেটা আপনার তথ্য চুরি করতে পারে, বা আপনার কাছে টাকা
চাইতে পারে।

সব আসল কপি একই ডিজিটাল সিগনেচার দিয়ে সাইন করা। নিচের প্রথম লাইনটা অ্যাপের আইডি, দ্বিতীয়টা সেই
সিগনেচারের ফিঙ্গারপ্রিন্ট:

```
io.github.liquidlyf
[SHA-256 FINGERPRINT]
```

আপনার ফোনের LiquidLyf আসল কি না দেখতে:

1. [AppVerifier](https://github.com/soupslurpr/AppVerifier) ইনস্টল করুন। এটা একটা ফ্রি, ওপেন সোর্স অ্যাপ।
2. ওপরের দুই লাইন সিলেক্ট করে **"শেয়ার করুন"** (<span lang="en">Share</span>) চাপুন, তারপর
   **AppVerifier** বেছে নিন।
3. AppVerifier আপনার ফোনের LiquidLyf-এর সাথে লাইন দুটো মিলিয়ে দেখবে, আর জানাবে মিলেছে কি না।

না মিললে ওই কপিটা আনইনস্টল করুন, এই পাতা থেকে LiquidLyf আবার নামান, আর
**[liquidlyf@gmail.com](mailto:liquidlyf@gmail.com)**-এ আমাদের জানান।

ডেভেলপারদের জন্য: প্রতিটা রিলিজে `SHA256SUMS.txt` আর একটা বিল্ড অ্যাটেস্টেশনও থাকে
(`gh attestation verify LiquidLyf.apk --repo liquidlyf/LiquidLyf`)।
