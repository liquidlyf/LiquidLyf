## কীভাবে ইনস্টল করবেন

LiquidLyf Play Store থেকে নয়, আমাদের ওয়েবসাইট থেকে ডাউনলোড হয়, তাই Android কয়েকটি বাড়তি প্রশ্ন করে।
প্রায় ২ মিনিট লাগে।

1. **ডাউনলোড করুন।** ওপরের ডাউনলোড বোতাম চাপুন। ব্রাউজার যদি সতর্ক করে যে "এই ধরনের ফাইল আপনার
   ডিভাইসের ক্ষতি করতে পারে", তাহলে **তবুও ডাউনলোড করুন** চাপুন।
   [SCREENSHOT 1]
2. **ফাইলটি খুলুন।** ডাউনলোডের নোটিফিকেশনে চাপুন, অথবা **Files** বা **Downloads** অ্যাপ খুলে
   `LiquidLyf.apk` চাপুন।
3. **ইনস্টলের অনুমতি দিন।** প্রথমবার Android বলবে আপনার ব্রাউজারের অ্যাপ ইনস্টলের অনুমতি নেই।
   **সেটিংস** চাপুন, **এই উৎস থেকে অনুমতি দিন** চালু করুন, তারপর ফিরে আসুন।
   [SCREENSHOT 2]
   *কিছু ফোনে (যেমন realme, Xiaomi বা Samsung) এই সুইচ থাকে সেটিংস → অ্যাপস → বিশেষ অ্যাপ অ্যাক্সেস →
   অজানা অ্যাপ ইনস্টল করুন-এ।*
4. **ইনস্টল করুন।** **ইনস্টল করুন** চাপুন।
5. **Play Protect সতর্কবার্তা দেখালে** **আরও বিস্তারিত → তবুও ইনস্টল করুন** চাপুন।
   [SCREENSHOT 3]
   অ্যাপটি Play Store থেকে নয় বলেই এই সতর্কবার্তা আসে। LiquidLyf ওপেন সোর্স: যে কেউ এর কোড পড়তে পারেন।
6. **LiquidLyf খুলুন** এবং Google বা আপনার ইমেইল ঠিকানা দিয়ে সাইন ইন করুন।

## এটা কি আসল LiquidLyf?

LiquidLyf শুধু এই পাতা থেকে বা
[আমাদের GitHub রিলিজ](https://github.com/liquidlyf/LiquidLyf/releases) থেকে ডাউনলোড করুন। অন্য যেকোনো
কপি নকল হতে পারে, যা আপনার তথ্য চুরি করতে বা আপনার কাছে টাকা চাইতে পারে।

প্রতিটি আসল কপি একই কী দিয়ে সাইন করা। তার ফিঙ্গারপ্রিন্ট:

```
App ID:  io.github.liquidlyf
SHA-256: [SHA-256 FINGERPRINT]
```

যাচাই করতে [AppVerifier](https://github.com/soupslurpr/AppVerifier) ইনস্টল করুন, ওপরের দুই লাইন কপি করুন,
তারপর AppVerifier খুলুন। এটি আপনার ফোনে ইনস্টল করা LiquidLyf-এর সাথে মিলিয়ে দেখে বলে দেবে মিলেছে কি না।
