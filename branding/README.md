# LiquidLyf logo

The heart-and-drop logo, redrawn as flat vector files from the original university-era design.
The logo and the name are **not** open-licensed; see [TRADEMARKS.md](../TRADEMARKS.md).

## Files

| File | What it is | Use it for |
|---|---|---|
| [logo-mark.svg](logo-mark.svg) | The heart and drop, full colour, 512 × 512 | App icon foreground, avatars, favicon, small spaces |
| [logo-mark-mono.svg](logo-mark-mono.svg) | The same mark as **one flat shape**: the drop ring and highlight are cut out, with no fold | Android's monochrome (themed) icon layer, single-colour printing (for example a white mark on red) |
| [logo-full.svg](logo-full.svg) | The mark above the "LiquidLyf" wordmark, for **light** backgrounds | README, website, documents |
| [logo-full-dark.svg](logo-full-dark.svg) | The same, for **dark** backgrounds | Dark mode, dark slides |
| [logo-horizontal.svg](logo-horizontal.svg) | The mark **beside** the wordmark, for light backgrounds | Website header, share images, wide spaces |
| [logo-horizontal-dark.svg](logo-horizontal-dark.svg) | The same, for dark backgrounds | The website header in dark mode |

All files are flat: filled paths only, with no gradients, shadows, filters, transforms or live text, and a
transparent background. Android Studio's **Vector Asset** tool imports them as they are.

## Colours

|---|---|---|
| Heart, drop | `#DE2027` | `#DE2027` |
| Fold (right side of the heart) | `#B71C22` | `#B71C22` |
| Drop ring, highlight | `#FFFFFF` | `#FFFFFF` |

| "Lyf" | `#534341` | `#D8C2BF` |

"Lyf" uses the app's `onSurfaceVariant` colours, light and dark. The app's own theme colours (seed
`#A4161A`) are a separate set, tuned for text and buttons.

## Typeface

The wordmark is **Montserrat Medium** (weight 500), converted to outlines. Montserrat is licensed under
the [SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/montserrat/OFL.txt), which
allows this. You don't need the font to use the logo.

## Android app icon (Phase 1.4b)

- **Background:** solid **white** `#FFFFFF` (the maintainer's choice, 15 Nov 2026). It replaces the
  red background with a white mark, chosen on 13 Nov.
- **Foreground:** the full-colour `logo-mark.svg`, with no text, inside the 66 dp safe zone of the
  108 dp canvas: with the shift below, its farthest point is 28.9 dp from the centre (the limit is 33).
- **Monochrome layer:** `logo-mark-mono.svg` (Android 13+ themed icons).
- **Built by** [app/scripts/generate_launcher_icons.py](../app/scripts/generate_launcher_icons.py), with
  the launcher, themed and splash icons. Re-run it after the logo files change.

### Optical centring

A heart is heavier at the top: its area centre is at y 220.5, the box centre at 256. Centred by its
box, the mark looks too high. So in **every square use** (the launcher icon, the splash screen,
avatars) the mark sits **18 units lower** in the 512 × 512 grid, half that gap. It stays centred
horizontally.

The SVG files in this folder are **not** shifted: their mark is centred on (256, 256). Add the shift
when you place the mark in a square. In the icon generator it's `OPTICAL_DY = 18`, which is 2.2 dp on
the 108 dp canvas. Keep using the unshifted mark in the full logo and anywhere it isn't alone in a
square.

## Using the logo

- Keep the proportions and colours as they are. Don't stretch, rotate, outline, or add shadows or gradients.
- Leave clear space around the logo of at least the height of the "L" in the wordmark (or 1/8 of the mark's width).
- Smallest sizes: the mark at 24 px, the full logo at 120 px wide, the side-by-side logo at 24 px tall.
- Use `logo-full-dark.svg` on dark backgrounds, not the light version.
- Never combine the logo with a red cross or a red crescent. Those emblems are protected by law.

## Rebuilding

The SVGs are generated by [build_logo.py](build_logo.py) from measured geometry, so a change (a colour,
the gap below the heart) is a one-line edit:

```bash
pip install fonttools
python build_logo.py path/to/Montserrat[wght].ttf .
python build_horizontal.py
```

[build_horizontal.py](build_horizontal.py) makes the side-by-side logos from the full ones, without the
font: it moves the same paths. The mark is twice the wordmark's cap height, and its optical centre (see
"Optical centring") lines up with the middle of the capitals.
