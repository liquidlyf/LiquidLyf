# LiquidLyf logo

The heart-and-drop logo, redrawn as flat vector files from the original university-era design.
The logo and the name are **not** open-licensed; see [TRADEMARKS.md](../TRADEMARKS.md).

## Files

| File | What it is | Use it for |
|---|---|---|
| [logo-mark.svg](logo-mark.svg) | The heart and drop, full colour, 512 × 512 | App icon foreground, avatars, favicon, small spaces |
| [logo-mark-mono.svg](logo-mark-mono.svg) | The same mark as **one flat shape**: the drop ring and highlight are cut out, with no fold | Android's monochrome (themed) icon layer, a white mark on red, single-colour printing |
| [logo-full.svg](logo-full.svg) | The mark above the "LiquidLyf" wordmark, for **light** backgrounds | README, website, documents |
| [logo-full-dark.svg](logo-full-dark.svg) | The same, for **dark** backgrounds | Dark mode, dark slides |

All files are flat: filled paths only, with no gradients, shadows, filters, transforms or live text, and a
transparent background. Android Studio's **Vector Asset** tool imports them as they are.

## Colours

| Part | Light backgrounds | Dark backgrounds |
|---|---|---|
| Heart, drop | `#DE2027` | `#DE2027` |
| Fold (right side of the heart) | `#B71C22` | `#B71C22` |
| Drop ring, highlight | `#FFFFFF` | `#FFFFFF` |
| "Liquid" | `#DE2027` (4.8:1 on white) | `#F2353B` (4.7:1 on `#1A1111`) |
| "Lyf" | `#534341` | `#D8C2BF` |

"Lyf" uses the app's `onSurfaceVariant` colours, light and dark. The app's own theme colours (seed
`#A4161A`) are a separate set, tuned for text and buttons.

## Typeface

The wordmark is **Montserrat Medium** (weight 500), converted to outlines. Montserrat is licensed under
the [SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/montserrat/OFL.txt), which
allows this. You don't need the font to use the logo.

## Android app icon (Phase 1.4b)

- **Foreground:** `logo-mark.svg`, with no text. Keep it inside the 66 dp safe zone of the 108 dp canvas.
- **Background:** a solid colour. Two options to try on the phone:
  - **(a)** red `#DE2027` background, with `logo-mark-mono.svg` filled white as the foreground;
  - **(b)** white background, with the full-colour `logo-mark.svg`.
- **Monochrome layer:** `logo-mark-mono.svg` (Android 13+ themed icons).

## Using the logo

- Keep the proportions and colours as they are. Don't stretch, rotate, outline, or add shadows or gradients.
- Leave clear space around the logo of at least the height of the "L" in the wordmark (or 1/8 of the mark's width).
- Smallest sizes: the mark at 24 px, the full logo at 120 px wide.
- Use `logo-full-dark.svg` on dark backgrounds, not the light version.
- Never combine the logo with a red cross or a red crescent. Those emblems are protected by law.

## Rebuilding

The SVGs are generated by [build_logo.py](build_logo.py) from measured geometry, so a change (a colour,
the gap below the heart) is a one-line edit:

```bash
pip install fonttools
python build_logo.py path/to/Montserrat[wght].ttf .
```

`build_logo.py` is code under the project's AGPL licence. The logo files it produces are covered by
[TRADEMARKS.md](../TRADEMARKS.md).
